### 🏷️ v1.0 - Panel territorial base (sin GeoJSON)

Primera versión funcional del sistema de monitoreo territorial ECH.

Incluye:

- 📍 Visualización de domicilios en mapa interactivo
- 🔥 Heatmap de actividad basado en logs
- 🧭 Registros de recorrido de encuestadores (GPS)
- 🔐 Control de sesiones (límite de paneles abiertos)
- 📊 Métricas básicas de actividad (eventos y hogares)
- 📌 Información de estado por domicilio
- 🔍 Filtro por usuario, encuesta y correlativo
- ⚠️ Validaciones de datos (coordenadas, usuario, encuesta)
- ⏳ Loader de carga del mapa

🚫 No incluye:
- Integración con GeoJSON
- Análisis por zonas territoriales
- Capas geográficas avanzadas

👉 Esta versión establece la base del sistema y la arquitectura del panel territorial.
