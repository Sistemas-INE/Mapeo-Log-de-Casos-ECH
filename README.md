# 🗺️ Mapeo Log de Casos ECH

Sistema de monitoreo territorial de la **Encuesta Continua de Hogares
(ECH)** con visualización geoespacial y análisis de actividad de
encuestadores.

------------------------------------------------------------------------

## 🚀 Descripción

Este sistema permite analizar y visualizar territorialmente la actividad
de encuestadores mediante un mapa interactivo.

Incluye:

-   📍 Ubicación de domicilios\
-   🔥 Mapas de calor basados en logs\
-   🧭 Recorridos GPS de encuestadores\
-   📊 Indicadores de productividad\
-   ⚠️ Detección de zonas sin actividad

------------------------------------------------------------------------

## 🛠️ Tecnologías utilizadas

-   Python\
-   FastAPI\
-   Oracle (cx_Oracle)\
-   Pandas\
-   Folium / Leaflet\
-   HTML / JavaScript
